# Web Minimalista · 02-calidad-sonarqube

Web estática (HTML, CSS y JavaScript) servida con Nginx. Estado al terminar la clase `02-calidad-sonarqube` de DevOps.

```bash
npm install          # si hay package-lock.json
npm run lint         # HTMLHint y ESLint
npm test             # tests con node --test
docker compose up --build   # la web en http://localhost:8080
```
