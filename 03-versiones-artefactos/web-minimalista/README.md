# Web Minimalista · 03-versiones-artefactos

Web estática (HTML, CSS y JavaScript) servida con Nginx. Estado al terminar la clase `03-versiones-artefactos` de DevOps.

```bash
npm install          # si hay package-lock.json
npm run lint         # HTMLHint y ESLint
npm test             # tests con node --test
docker compose up --build   # la web en http://localhost:8080
```
